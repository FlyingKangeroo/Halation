First pre-release of Halation: open-source film grain, halation, bloom and damage for **Adobe Lightroom Classic**.

## What's in this release

- **Lightroom Classic plug-in** (`Halation.lrplugin-0.1.0.zip`): adds *Edit in Halation…* under *File ▸ Plug-in Extras* and *Library ▸ Plug-in Extras*. Renders the selected photos as 16-bit TIFFs, hands them to the editor, and imports the results stacked under the originals. Settings panel for app location, hand-off colour space (sRGB / Adobe RGB / ProPhoto RGB) and temp TIFF compression.
- **Editor, browser build** (`halation-web-0.1.0.zip`): the WebGL2 editor as static files. Serve the folder with any static server (for example `npx serve .`), then open or drop a TIFF/JPEG/PNG; *Export TIFF* downloads a 16-bit TIFF. Useful for trying the look without Lightroom.
- **Effects**: six grain presets (Super 8, 16mm, Classic 35mm, Fine 35mm, Medium format, Pushed B&W) with full manual control; halation with tint; bloom; dust, scratches, light leak and vignette. Everything is resolution independent, so the preview matches the full-resolution export.
- **UI**: minimalist Liquid Glass inspired chrome, light and dark.

- **Desktop app**: macOS (Apple silicon and Intel) and Windows bundles built by the release workflow. The Lightroom plug-in launches this app; the browser build cannot be used from Lightroom.

## Installing the desktop app

The bundles are not code-signed yet. On macOS, right-click the app and choose *Open* the first time (or run `xattr -dr com.apple.quarantine /Applications/Halation.app`). On Windows, choose *More info ▸ Run anyway* in SmartScreen.

## Known gaps

- The Tauri shell has not been compiled in CI yet; the first desktop build may need small fixes in `app/src-tauri/`.
- Icons are placeholders.
- Images larger than the GPU's maximum texture size (usually 16384 px) are rejected rather than tiled.
